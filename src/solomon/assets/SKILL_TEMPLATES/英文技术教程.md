## 翻译规则

### 必须翻译的内容
- 课程介绍、方法讲解
- 操作步骤说明
- 错误提示和警告
- 学习建议和总结

### 保留英文的情况
1. **专业术语**（首次出现时加中文注释）：
   - Critical Thinking（批判性思维）
   - Deductive Reasoning（演绎推理）
   - API（应用程序编程接口）

2. **工具/软件名称**：
   - Claude Code、Notion、VS Code、GitHub
   - Docker、Kubernetes、Python

3. **代码和命令**：
   ```bash
   # 所有代码示例保留英文
   npm install package-name
   ```

4. **文件名和路径**：
   - `config.yaml`、`/usr/local/bin/`

### 翻译质量要求
- **提供学习价值，不是简单翻译**：解析内容本质，用中文清晰解释"为什么"和"怎么做"，而非逐句对照翻译
- 准确传达原意，不是字面翻译
- 符合中文技术文档习惯
- 保持专业性，避免口语化
- 代码注释可以翻译为中文
- 主动增加对比表格、学习路径、自测问题等学习辅助内容

## 写作规则

1. **翻译优先级**：准确 > 通顺 > 优雅
2. **术语一致性**：同一术语全文统一翻译
3. **图片用 wiki embeds**：`![[filename.jpg]]`，不用 `./assets/` 路径
4. **每张图后必须有教学说明**：告诉读者从图里学到什么
5. **不能有独立截图子标题**：如 "### 画面回顾"、"### 截图"
6. **宁多勿少**：覆盖所有知识点、示例、步骤
7. **图片文件名保持原样**：wiki embed必须与keyframes_deduped/中的实际文件名完全一致
8. **代码块保留英文**：代码本身不翻译，注释可以翻译
9. **保留关键英文术语**：方便读者后续搜索和学习

## 质量门槛

| 视频时长 T | 最小笔记大小 | 最小图片数 |
|-----------|------------|----------|
| T ≤ 10min | 2KB | 2张 |
| 10 < T ≤ 20min | 4KB | 3张 |
| T > 20min | 超时长=T-20, 档位=floor(超时长/20), KB=4+档位×2, 图=3+档位 |
| 封顶 | 60KB | 30张 |
