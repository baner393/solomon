# 技术编程笔记模板

> 设计参考：kepano-obsidian 资源属性化（frontmatter 记 tech_stack/topics/running）+ Zettelkasten
> 的 Details/Questions/Tasks 三段式；ytkn「Study notes」（学习/复习/自测）目标
> 适用：编程实战、代码开发、工程实现类视频（"用 X 写一个 Y"、"Python 实战"）
> 目标：可复用、可复习的代码资产（实现 + 架构 + 可运行验证），关键代码是核心

## 写作要点

1. **代码高于流程**：技术编程的核心资产是可复用的代码片段；每条代码说明「解决什么、关键在哪」
2. **架构单独立节**：懂"代码怎么组织"比懂"每行干嘛"更能迁移复用
3. **依赖/版本写具体**：`pip install X==1.2.3`
4. **「运行验证」必须写**：怎么跑、跑通的标准是什么（kepano 模板强调可复现）
5. **踩坑按「问题-原因-解决」三列**（ytkn gotchas）
6. **配图用 wiki embed**：`![[filename.jpg]]`，运行结果/界面图插代码后
